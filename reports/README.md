# Reports moved

Daily availability measurements now live in their own repository:

https://github.com/tiredvpn/tiredvpn-measurements

That archive holds the human-readable `report.md` for each day plus the
per-attempt JSON (latency and error type per strategy, per ISP, per server).

The reports that used to live here (2026-05-28 .. 2026-06-23) stay in this
repo's git history and are re-published in full - now with the JSON backfill -
in the measurements repo. The stand pushes there directly from now on.
